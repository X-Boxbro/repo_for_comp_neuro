## 当前重点

1. 把神经元理解为动力系统。
2. 实现并分析漏积分发放（LIF）模型。
3. 连接噪声、脉冲序列变异性与随机过程。
4. 使用概率论、傅立叶分析和随机过程理解神经信号。

## 工作原则

- 优先做规模小、可以运行的实验，而不是无止境收集资料。
- 让方程、假设、代码和图表彼此保持清晰对应。
- 明确区分 toy model 与完整的生物学仿真。
- 成功结果、模型限制和未解决问题一起记录。
