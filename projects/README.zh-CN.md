# 计算项目

这个目录存放把学习笔记中的概念转化为可运行实验的小型项目。

## 模块

- [LIF 模型](./lif/README.zh-CN.md) - 带噪声和背景脉冲的积分发放神经元仿真。
- [动力系统](./dynamics/README.zh-CN.md) - 相平面、零流线、不动点和局部稳定性分析。
- [Neural decoding toy](./decoding_toy.py) - 使用脉冲响应进行分类的小型实验。

## 共同约定

每个项目应说明模型、参数、数值方法、预期输出和已知限制。当代码重复达到值得抽象的程度后，再考虑移动到共享源码目录。
