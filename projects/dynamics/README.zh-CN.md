# 动力系统

这个项目通过二维相平面方法观察计算神经科学中的动力学行为。

## 当前功能

- 绘制二维系统的向量场和流线。
- 绘制 `F(x, y) = 0` 与 `G(x, y) = 0` 两条零流线。
- 数值寻找不动点。
- 使用 Jacobian 矩阵的特征值分析不动点的局部稳定性。
- 支持输入非线性的 `F` 和 `G`。

## 文件

- [`dynamics.py`](./dynamics.py) - `PhasePlane` 二维相平面工具。

## 当前限制

- 目前只支持二维系统。
- 不动点通过数值方法寻找，复杂系统可能漏检。
- 稳定性分析仅适用于不动点附近的局部行为。
