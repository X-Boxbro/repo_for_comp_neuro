# Computational Projects

This directory contains small simulations that turn concepts from the learning notes into executable experiments.

## Modules

- [LIF model](./lif/README.md) - Integrate-and-fire neuron simulation with noise and background spikes.
- [Dynamical systems](./dynamics/README.md) - Phase-plane visualization, nullclines, fixed points, and local stability.
- [Neural decoding toy](./decoding_toy.py) - A small classification experiment using spike responses.

## Shared conventions

Projects should state the model, parameters, numerical method, expected output, and known limitations. Reusable implementation can later move into a shared source directory when duplication becomes meaningful.
