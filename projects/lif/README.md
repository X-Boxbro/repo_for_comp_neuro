about LIF(Leaky Integrate-and-Fire) model

1.模型用处：
作为一个基本的大脑信息传递单元，是研究大脑运行机制和信息传递机制的基础
2.模型的原理：
神经元有动作电位--观测到的生物学事实
将神经元的信息传递过程抽象为一个物理模型，然后用动力学方程表示电量之间的关系
输入信号I(t)电流，输出信号V(t)膜内外电压。
模型将神经元膜电压的变化描述为一个积分器，当膜电压超过阈值时，神经元会发放一个动作电位，并将膜电压重置为静息电位。

积分过程可以用以下微分方程表示：
RC * du/dt = -u + R*I(t)
RC=tau为膜时间常数，R为膜电阻，C为膜电容，u为膜电压，I(t)为输入电流。

激活过程在实际生物学中的信号形状基本保持一致，是放电的时刻作为信息传递的载体起作用。
过程用数组直接记录放射时间即可。
if u(t) >= Vth,Fire[t] = 1 and u(t) = u_reset
else Fire[t] = 0

3.不足
对于膜上离子通道的电流没有足够详细的描述，无法解释生物学/化学上的复杂机制
