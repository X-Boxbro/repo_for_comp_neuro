# 漏积分发放模型（LIF）

这个项目实现了一个最小的 LIF 神经元群体模型。膜电位对输入电流进行积分，同时向静息电位泄漏；达到阈值后记录脉冲并重置膜电位。

## 文件

- [`lif.py`](./lif.py) - LIF 仿真、高斯噪声、背景脉冲以及绘图。

## 模型

亚阈值动力学写作：

```text
tau * du/dt = R * I(t) - (u - u_rest)
```

当前实现使用 Euler 方法进行数值积分。当 `u >= u_th` 时记录一次脉冲并重置膜电位。
